# 간편 거래명세서

농산물 중도매인용 거래명세서 프로그램 (거래돌이 대체). 윈도우 10/11.

## 내려받기
**[간편거래명세서.zip 내려받기](https://github.com/wndlftnr4669-svg/georae-statement/raw/main/download/간편거래명세서.zip)**

압축을 풀고 `간편거래명세서.exe`를 실행하세요. `resources.neu`와 같은 폴더에 있어야 해요.
한 번 깔면 그다음부터는 켤 때 자동으로 업데이트돼요. 자세한 건 압축 안의 `사용법.txt`를 보세요.

## 주요 기능
- 거래명세서 작성 · A5 인쇄 (거래처용 / 내 가게용), 매입 기록
- 거래처 미수 · 미지급, 원장, 입금 · 지급
- 거래 내역 일 · 월 · 연 검색, 엑셀 저장
- 거래돌이 백업(.mdb) 가져오기
- 자동 업데이트

## 폴더 구성
- `app/` : 프로그램 소스 (Neutralinojs 6.4.0). 화면과 기능은 전부 `app/resources/index.html` 한 파일.
- `update/` : 자동 업데이트용 파일 (`manifest.json`, `resources.neu`) — 프로그램이 여기를 확인해요.
- `download/` : 처음 까는 사람용 zip.
- `tools/release.sh` : 새 버전 만들기.

※ 거래 자료(거래처, 명세서 등)는 각 컴퓨터에만 저장되고 이 저장소에는 올라오지 않아요.

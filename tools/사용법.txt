[간편 거래명세서 사용법]

■ 설치
1. 압축을 풀면 "간편거래명세서.exe"와 "resources.neu" 두 파일이 있어요. 두 파일은 꼭 같은 폴더에 두세요.
   (바탕화면 말고 "문서" 안에 "간편거래명세서" 폴더를 만들어서 넣는 걸 추천해요)
2. "간편거래명세서.exe"를 더블클릭하면 실행돼요.
   - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]
   - 바탕화면 바로가기: exe 파일 오른쪽 클릭 → [보내기] → [바탕 화면에 바로 가기 만들기]
3. 업데이트는 자동이에요. 켤 때 새 버전이 있으면 물어보고, [지금 업데이트]만 누르면 돼요.

■ 윈도우 백신이 프로그램을 지울 때 (오진)
   개인이 만든 프로그램이라 Windows 보안(디펜더)이 가끔 바이러스로 잘못 알고 지워요. 아래처럼 한 번만 해두면 돼요.
   1) 시작 → "Windows 보안" → [바이러스 및 위협 방지]
   2) [바이러스 및 위협 방지 설정] 아래 [설정 관리]
   3) 맨 아래 [제외] → [제외 추가 또는 제거] → [제외 사항 추가] → [폴더] → 프로그램을 넣어둔 폴더 선택
   4) 이미 지워졌으면: [바이러스 및 위협 방지] → [보호 기록]에서 해당 항목 → [작업] → [허용] 또는 [복원]
   ※ 자료(거래처·명세서)는 프로그램 폴더가 아니라 사용자 폴더에 따로 저장돼서, 프로그램이 지워져도 자료는 남아 있어요.

■ 처음 할 일
   [설정 · 백업]에서 우리 가게 정보(상호, 사업자번호, 대표자, 주소 등) 입력
   거래돌이를 쓰던 자료는 [설정 · 백업] → [거래돌이 백업 파일 고르기]로 한 번에 옮겨와요. (30초쯤 걸려요)

■ 명세서 쓰기
   - 품목 칸에 글자를 치면 목록이 떠요. ↑↓로 고르고 Enter 하면 규격·단위·단가까지 채워져요.
   - 수량을 치고 Enter → 단위(1 박스 · 2 Kg · 3 g · 4 개 · 5 단) 선택
   - 방향키(← → ↑ ↓)로 칸 이동
   - 내가 산 물건은 [매입으로 기록]을 체크하고 입력
   - [저장 후 인쇄]: 기본은 A5 용지에 거래처용 1장 + 내 가게용 1장
     인쇄창 [기타 설정]에서 용지 크기 = A5, 여백 = 기본값, 머리글 및 바닥글 체크 해제
     거래처용 1장만 뽑으려면 [설정 · 백업] → 인쇄 매수

■ 거래 내역
   일별 · 월별 · 연별 · 기간 · 전체 / 매출 · 매입 따로 또는 같이 / 거래처·품목 검색 / [엑셀로 저장]

■ 자료 백업
   자동 저장 + 하루 한 번 자동 백업(최근 10일치). 컴퓨터를 바꿀 땐 [설정 · 백업] → [백업 파일 받기] 한 파일을
   새 컴퓨터에서 [백업 파일 불러오기] 하면 돼요.

※ 윈도우 10 / 11에서 동작해요.
